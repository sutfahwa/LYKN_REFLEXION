# LYKN Reflexion Concert

เว็บไซต์คอนเสิร์ต LYKN Reflexion Concert — 24-25 ตุลาคม 2569 ณ อิมแพ็ค อารีน่า เมืองทองธานี

Static single-page site built with the Claude Design (`dc-runtime`) format — `index.html` embeds an
`<x-dc>` template + a small React-based component (`support.js` interprets it, loading React/ReactDOM/Babel
from a CDN at runtime). No build step required; it's plain static files.

## Structure

- `index.html` — the page (nav, countdown, concert details, tips, FAQ, lucky-draw gacha)
- `support.js` — dc-runtime that parses/renders the `<x-dc>` template (generated, do not hand-edit)
- `image-slot.js` — user-fillable image slot custom element (unused on this page, kept for parity with the design source)
- `assets/` — logo, nav logo, seat plan, payment badges, gacha cards, favicons
- `netlify.toml` — Netlify deploy config

## Favicon

`assets/favicon*.png`, `assets/favicon.ico`, and `assets/apple-touch-icon.png` were generated by
cropping the "LYKN" wordmark out of `assets/logo.png` and cutting the black background to transparency.

## Run locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Deploy to Netlify

**Option A — CLI:**
```bash
npx netlify-cli deploy --prod
```

**Option B — Git integration:** push this repo to GitHub, then in Netlify: "Add new site" →
"Import an existing project" → pick the repo. Build command: none. Publish directory: `.`
